# 🌌 Aurora

> An interactive storytelling experience built with web technologies for iPhone.

Aurora es una experiencia web diseñada para contar una historia de forma inmersiva, culminando en una sorpresa en Realidad Aumentada (AR) mediante Quick Look en iOS.

---

## 🚀 Objetivo

Crear una experiencia emocional y minimalista inspirada en el estilo de Apple, donde cada sección del recorrido acerque al usuario a una sorpresa final.

---

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6)
- GSAP
- GSAP ScrollTrigger
- AR Quick Look (USDZ)
- Progressive Web App (PWA)
